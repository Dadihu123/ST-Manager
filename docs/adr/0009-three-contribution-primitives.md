# 贡献通道只有三原语：菜单树、插槽、命令

为避免重新陷入「每有一种 UI 概念就加一个 kind」的枚举增长，2026-10-21 决定：宿主 UI 的声明式扩展只保留三类原语——**菜单树**（含子菜单/分组/分隔/排序/条件/动态徽标）、**插槽**（宿主 UI 内的命名嵌入点，插件渲染器在宿主容器内自绘）、**命令**（具名动作，可被菜单项、命令面板或快捷键复用）。设置分区、状态项、坞徽标等用插槽或菜单项表达，不再单列通道。

**Status**: accepted

**Consequences**:

- 新 UI 诉求优先映射到这三类；映射不了时用插槽渲染器自绘，而不是新增 kind。
- 「贡献类型」的枚举从此稳定；新增的是落点/插槽的名称，而不是新的声明种类。
