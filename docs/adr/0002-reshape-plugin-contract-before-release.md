# 发布前一次性重塑插件契约

插件系统尚未公开发布，已安装的三个插件（hello-world、stm-ai-assistant、stm-pet）均为自研，没有外部兼容负担。2026-10-21 决定：在发布前把契约一次性重塑为「贡献通道 + 自绘模式」的新形态，`entries[]` 不作为长期兼容层保留，内部插件同步迁移；发布后按稳定性分级与 deprecation 规则演进。

**Status**: accepted

**Considered Options**:

- 保留 `entries[]` 并叠加新模型：会让「同一份声明多条渲染路径」的问题长期存在，否决。
- 发布后再重塑：首批第三方将照旧契约开发，之后的重塑会变成破坏性变更，否决。
