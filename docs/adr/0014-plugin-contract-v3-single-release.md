# 插件契约 v3 一次成型

2026-10-21 决定：本次重塑在一个发布窗口内一次成型——三原语（菜单树 / 插槽 / 命令）、`createRoot` / portal、共存协调（overlay 注册与 kill switch）、原语库补齐（menu / popover / tabs / layout）、机器可读契约与 `stm-plugin-check`、三个官方插件迁移、文档与示例。内部按依赖排序交付，但对外只有一个 v3 契约版本。

**Status**: accepted

**Consequences**:

- 不建议把契约工具链或原语库拆到 v3.1，否则第一批第三方会在「契约已发布、工具不完善」的状态下接入。
- 实现顺序建议：契约定义与生成器 → 三原语渲染器 → 根节点/共存 → 原语库 → 官方插件迁移。
