# 宿主 UI 只接受声明式贡献与插槽渲染器

插件自有界面归插件（ADR-0001），但宿主 UI（右键菜单、批量栏、header、设置页、命令面板）的结构仍归宿主。2026-10-21 决定：插件进入宿主 UI 只有两种方式——**声明式贡献**（插件提交数据，宿主渲染，用于菜单树/命令/排序/条件）与**插槽渲染器**（宿主提供有边界的容器，插件在容器内自绘内容）；不支持按宿主选择器直接注入 DOM，直接注入属于不受支持的用法。

**Status**: accepted

**Considered Options**:

- 只允许声明式贡献：插件在宿主 UI 里无法放自绘内容，表达力不足，否决。
- 允许直接 DOM 注入：宿主模板一变插件就静默错位，且无法强制回收，否决。
