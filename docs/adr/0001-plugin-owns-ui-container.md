# 插件拥有自己的 UI 容器

原设计（F13/F14）要求容器归宿主、插件不得自绘 `position: fixed` 浮层，以保证层级、移动端适配与可回收性。2026-10-21 用户裁定：开放给第三方后不能把界面形态限制死——用户可自行选择安装哪些插件，也可能接受多悬浮窗；因此宿主不再强制容器归属，继续提供可选的宿主容器、UI 原语与共存规则，但插件可以自建容器与浮层。

**Status**: accepted

**Consequences**:

- 「不得自绘浮层」从硬约束降为默认建议；插件仍需保证其 UI 在禁用/卸载后可被整体回收，具体方式（根节点约定或 portal 注册）留待共存契约设计。
- 宿主必须提供共存契约（层级带、portal root、浮层协调、崩溃隔离），否则多插件互相遮挡无法治理。
- 宿主 UI 自身（菜单、设置页、header）的结构与视觉一致性不再能靠"禁止插件自绘"保证，只能靠推荐通道的吸引力与文档引导。
