# 保留 CSS 作用域，全局样式需显式权限

插件将获得自绘界面的自由，但「污染宿主与其他插件的界面」不属于表达自由。2026-10-21 决定：安装期继续强制插件 CSS 作用域（以 `.plugin-<id>` 或 `[data-plugin="<id>"]` 为根）；需要全局换肤/主题类效果的插件通过显式权限 `ui.global_styles` 申请，安装与启用时向用户披露。

**Status**: accepted

**Considered Options**:

- 连 CSS 作用域一并放开：一个坏插件会让所有插件看起来都坏了，且替代隔离方案（Shadow DOM / iframe）与「无沙箱」取舍冲突，否决。
- 维持全面强制、不开全局样式出口：会让「主题/换肤类插件」这一类合法第三方需求无法实现，否决。
