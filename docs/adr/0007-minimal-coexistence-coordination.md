# 多插件共存采用最小协调

自绘模式放开后，多插件浮层可能互相遮挡；用户只能选择装不装插件，无法判断冲突来自谁。2026-10-21 决定：宿主不做强协调（不接管插件浮层的定位与层级），只提供最小共存契约——层级带作为建议值；插件**可选**地向宿主登记自绘浮层（用于 ESC、焦点、遮挡通知与调试）；宿主**必须**提供崩溃隔离与一键关闭所有插件浮层的止损开关。

**Status**: accepted

**Considered Options**:

- 不协调：两个插件都用 `z-index: 9999` 会成为必然事件，用户无法定位是谁的问题，否决。
- 强协调（所有浮层必须经宿主 overlay 管理器）：等于退回「容器归宿主」，与 ADR-0001 冲突，否决。
