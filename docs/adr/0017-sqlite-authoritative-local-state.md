# SQLite 保存权威本地状态，JSON 作为迁移输入与显式导出

2026-11-17 决定：角色卡 UI 状态与聊天本地状态保存到现有运行时数据库，
由 `core/data/local_state_repository.py` 管理。`ui_data_cache`、搜索索引和聊天文件
统计仍是派生数据，不参与权威源切换。

**Status**: accepted

**Consequences**:

- `ui_records` 保留原有路径 key 和完整记录；`chat_local_state` 保留阅读器既有协议。
  `_` 开头的对象命名空间按直接成员保存到 `ui_namespace_records`，未知非对象值原样保留。
  聊天及资源绑定使用派生的双向索引，不为查询绑定反序列化全部 UI 记录。
- 旧 load/save 门面返回按需读取的带基线快照。提交只合并访问过且修改过的字段；
  不同字段可合并，同字段冲突拒绝。无基线数据不能覆盖已有记录；全表替换只供显式导入。
- UI 记录、已有卡片搜索投影和 `index_jobs` 意图共用事务。内部增量接受 `commit=False`，
  不能提交调用者事务。文件读取、编码和 hook 在短写事务之外进行。
- 同步增量按活动索引代、UI 记录 revision 和文件 source revision 确认投影，只确认准备前的
  任务范围。卡片重建期间写入旧代的卡片 ID 按构建代去重暂存；激活新代的同一事务将它们转为
  增量任务，worker 再读当前数据。丢弃未激活的构建代时一并丢弃它的暂存记录。升级无代号的历史
  凭据时，仅为活动索引中缺失或摘要不符的卡片补任务。
  文件替换前持久化恢复意图；恢复读取实际文件，不重放旧正文。失败意图保留并
  重试，成功历史有界保留。文件已落盘而 SQL 失败时，API 明确报告已保存部分。
- 权威数据库使用 WAL 和 `synchronous=FULL`。卡片锁先于 repository 写事务；维护门禁
  阻止备份切换与普通写入交错。不要在缓存锁内调用 repository 或访问外部资源。
- 本地状态 schema v2 将旧世界书备注路径键迁移为当前规范键。规范键与旧键冲突时优先
  保留规范键的有效备注，否则选择排序最前的有效别名；所有未胜出的原值保留在
  `legacy-conflict::` 键下。首次激活及已激活的 v2 库升级到 v3 时，按当前索引构建规则
  核对活动世界书的实际摘要。有差异时，在同一事务内持久化重建任务。v1 升级继续为已有
  世界书索引安排重建，以补偿旧版丢失的刷新任务。迁移任务记录原活动代。若启动升级已激活
  新代，worker 在同一读事务内确认搜索格式和摘要均已更新后即可完成任务。
  备注修改和刷新任务共用一次 FULL 事务，任一写入失败就一起回滚。共享资源备注按路径
  入队一次，worker 重新解析当前绑定及仍有投影的角色，在同一事务内更新它们。没有绑定也没有
  旧投影时可完成该条备注任务；它不能代替同批其他任务所需的首次重建。
- 服务、插件和 worker 启动前独占迁移。旧文件与备份世代保留，SQLite backup 包含已提交
  WAL。`preparing` 可重新导入，`imported` 可继续原子激活，`activated` 不再导入旧 JSON。
  `.local-state-authority` 标记防止已激活数据库缺失后误用陈旧 JSON。
- 迁移预算为每个旧 JSON 512 MiB；损坏、不可达、激活失败不等于首次运行。
  激活后的库异常拒绝写入及旧 JSON 回退，保留配置、显式恢复入口。
- 完整归档读取 SQLite 权威快照并输出兼容 JSON，经过路径转换、校验和 staging 激活。
  已发布的选择性用户 DB 备份恢复继续只恢复原先的选择性字段。
- 文件 source revision、UI revision、图片内容 revision 相互独立。PNG 文本块改写保留图像
  压缩流和非角色附加块；缩略图有效性由图片内容与算法版本决定。

迁移、降级导出与故障操作见 `docs/DEVELOPMENT.md`。性能验证记录为本地文档，不是运行或
测试依赖；完整 SQL 卡片列表、聊天目录索引及 SQL 分页另行实施。

2026-11-17 审查修订：namespace 整体替换/删除校验观察到的根 revision，不能将懒快照
在保存时重新读到的值当作旧基线。显式外层连接及嵌套 savepoint 不确认快照基线；事务
拥有者真正 commit 后才能调用 `StateSnapshot.confirm_saved()`，回滚后的原快照可重试。
文件意图保存最终路径、旧/新 ID、UI 前缀及 bundle UI key；像素和元数据先完整暂存，
正式替换后即使退出进程也可从实际文件恢复。缓存全量重载批量预取 UI，不计算全库图片
摘要。FTS 映射结构升级修复执行一次；显式 `repair_full_search_mapping` 用于异常修复。
损坏目标库不阻断已验证完整归档的恢复，不能提取的本机插件配置/凭据需明确报告，保留
旧库保护副本且禁用恢复后的插件，不从陈旧 JSON 补回凭据。
