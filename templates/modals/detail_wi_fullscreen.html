{{ icon('layout', 'ui-icon--sm') }} 界面布局

全屏世界书编辑器采用三栏布局：

  • 左侧列表 - 显示所有条目，可点击选择、拖拽排序
  • 中间编辑区 - 沉浸式编辑当前条目的内容
  • 右侧面板 - 属性设置与剪切板管理

{{ icon('book-tip', 'ui-icon--xs') }} 提示：在移动端可收起左右面板以扩大编辑区域

{{ icon('settings-save', 'ui-icon--sm') }} 保存方式

{{ icon('settings-save', 'ui-icon--xs') }} 保存条目

保存当前条目的修改。如果是独立世界书文件，直接保存到文件；如果是内嵌世界书，保存到角色卡。

{{ icon('book-save', 'ui-icon--xs') }} 保存整本

先创建整本回滚版本（备份旧状态），再执行保存。适合大改前使用，可随时回滚整本。

{{ icon('book-save-as', 'ui-icon--xs') }} 另存为...

将当前世界书保存为新文件。内嵌世界书可提取为独立的全局世界书文件。

{{ icon('history-rollback', 'ui-icon--sm') }} 备份、快照与时光机

{{ icon('snapshot', 'ui-icon--md') }}
创建快照

左键点击创建普通备份，右键点击创建关键节点备份（标记为重要版本）。

{{ icon('history-rollback', 'ui-icon--md') }}
时光机（整本回滚）

查看所有历史版本，可选择任意时间点回滚整本世界书。支持对比不同版本的差异。

{{ icon('entry-rollback', 'ui-icon--md') }}
条目历史回滚

点击条目右侧的 {{ icon('entry-rollback', 'ui-icon--xs') }} 按钮，可查看该条目的所有历史版本，支持行级差异对比和单条目回滚。

{{ icon('book-backup', 'ui-icon--md') }}
打开备份文件夹

快速打开存储备份文件的目录，方便手动管理或导出。

{{ icon('clipboard', 'ui-icon--sm') }} 剪切板系统

剪切板是一个全局存储空间，可跨条目、跨世界书复制粘贴内容：

  • 复制到剪切板 - 点击条目的 {{ icon('clipboard', 'ui-icon--xs') }} 按钮
  • 从剪切板添加 - 在剪切板面板点击 {{ icon('plus-square', 'ui-icon--xs') }} 按钮
  • 编辑剪切板 - 点击剪切板中的条目可直接编辑，修改后保存不影响原条目
  • 清空剪切板 - 点击右上角的"清空"链接

{{ icon('alert-triangle', 'ui-icon--xs') }} 注意：剪切板内容存储在数据库中，重启后仍然保留。

{{ icon('sliders-settings', 'ui-icon--sm') }} 条目属性详解

触发策略

{{ icon('pin', 'ui-icon--xs') }} 常驻 (Constant)

始终激活，不依赖关键词触发。适合世界观、背景设定等必须始终存在的内容。

{{ icon('wand', 'ui-icon--xs') }} 向量化 (Vectorized)

使用向量匹配而非关键词，适合语义相似的场景。与常驻互斥。

{{ icon('key-trigger', 'ui-icon--xs') }} 关键词触发 (Normal)

默认模式，需要匹配关键词才会激活。主触发词和次要/过滤词配合使用。

关键词设置

主触发词 (Primary Keys)

用逗号分隔，匹配任一即可触发条目。支持正则表达式（需在高级逻辑中开启）。

次要/过滤词 (Filter Keys)

可选。启用"选择性逻辑"后，这些词决定条目是否真正被插入。

插入设置

位置 (Position) 决定内容插入到对话的哪个部分
权重 (Order) 数值越小越靠前，控制多个条目的插入顺序
深度 (Depth) 仅在"@层级"位置时有效，控制插入深度

递归与流程

不可递归 - 该条目不会被递归扫描触发

阻止后续递归 - 激活后停止后续递归扫描

无视限额 - 即使超出预算也强制插入（慎用）

延迟递归等级 - 延迟到指定递归深度才激活

高级逻辑

逻辑模式
  • 0 - 任意匹配 (OR)
  • 1 - 全部匹配 (AND)
  • 2 - 全不匹配 (NOR)
  • 3 - 非全部 (NAND)
匹配选项
  • 全词匹配 - 匹配完整单词
  • 区分大小写 - 严格大小写
  • 正则模式 - 使用正则匹配
触发概率

启用后可设置 0-100% 的随机触发概率，适合随机事件或变体内容。

{{ icon('book-search', 'ui-icon--sm') }} 查找与替换

支持在当前条目或全部条目中进行查找替换：

  • 快捷键 - 按 Ctrl+H 快速打开
  • 排除文本 - 可设置不参与替换的文本区间（如 {{user}}）
  • 可拖动 - 面板可拖动，方便查看底层文本
  • 范围选择 - 支持"当前条目"或"全部条目"
