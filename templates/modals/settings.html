GUIDE /

{{ icon('folder-path', 'ui-icon--sm') }}路径如何填写

每个目录都支持相对路径和绝对路径。相对路径以 ST-Manager 的数据目录为基准，适合保持配置可迁移；绝对路径适合直接接入已有的 SillyTavern 或素材目录。

  • 角色卡、世界书、聊天与预设：分别对应管理器中的四类内容。
  • 资源、正则、脚本与快速回复：用于附件、扩展资源和全局工具的统一浏览。
  • ST Chat Completion 预设：填写 SillyTavern 的 OpenAI 预设目录后，才能检测和同步对应预设。

{{ icon('shield-check', 'ui-icon--sm') }}路径安全与同步

编辑路径时会自动检查 ST 根目录与管理目录是否重叠。发现风险后，页面会列出具体冲突；保存或同步前请确认目标目录，避免把同一批文件重复当作来源和目标。

{{ icon('alert-triangle', 'ui-icon--sm') }}修改路径后建议执行一次“立即扫描”，让数据库索引与磁盘内容重新对齐。

{{ icon('display', 'ui-icon--sm') }}主题、字体与布局

  • 深浅色模式与强调色：会立即预览，影响整个管理器的表面、按钮、选中态和焦点提示。
  • 字体风格与卡片特效：分别控制阅读字形和角色卡的悬浮视觉效果。
  • 卡片尺寸、分页和排序：只改变列表的展示密度；每页数量为“自动”时会根据窗口宽度计算。
  • 隔离分类：隐藏分类在上级目录和搜索结果中的出现，但进入分类自身后仍可正常浏览。

{{ icon('wallpaper', 'ui-icon--sm') }}壁纸与美化

可以使用 URL、本地上传或共享壁纸库设置管理器背景；不透明度和模糊度用于平衡背景效果与文字可读性。主题与字体的更改只是即时预览，保存后才会写入配置。

{{ icon('shield-key', 'ui-icon--sm') }}ST 认证模式排查

先打开 SillyTavern 根目录中的 config.yaml，重点查看 basicAuthMode、enableUserAccounts、perUserBasicAuth 和 basicAuthUser。

  • Basic/Auth：适合 basicAuthMode: true 且不使用 Web 账号登录的情况。
  • Web/Login：适合 basicAuthMode: false 且 enableUserAccounts: true 的情况。
  • Basic Auth + Web Login：适合两者同时开启的情况。
  • perUserBasicAuth: true 时，Basic 认证复用 Web 账号的 handle 和密码；为 false 时使用 basicAuthUser.username/password。
# Basic/Auth
basicAuthMode: true
enableUserAccounts: false
perUserBasicAuth: false
basicAuthUser:
  username: admin
  password: change-me

# Web/Login
basicAuthMode: false
enableUserAccounts: true
{{ icon('alert-triangle', 'ui-icon--sm') }}Web 用户名是账号 handle；Web 密码无法直接查询，只能验证、修改，忘记时请使用 SillyTavern 官方 recover.js 流程重置。

{{ icon('plug', 'ui-icon--sm') }}SillyTavern 连接与同步

  • 安装根目录应包含 SillyTavern 的 data/、public/ 和 server.js。
  • 可以先点击“自动探测”，再点击“验证目录”确认资源数量和目录结构。
  • 同步按钮会遵守路径安全拦截；同步前请确认目标目录，必要时先保存地址和认证配置。

{{ icon('settings-connection-service', 'ui-icon--sm') }}Discord 论坛标签抓取

Discord 认证用于自动化规则从类脑论坛帖子抓取标签，和类脑帖子预览使用的 Cookie 相互独立。

获取 Discord Token
  1. 在浏览器打开 Discord 网页版并登录，进入可访问类脑帖子的频道。
  2. 按 F12 打开开发者工具，切换到 Console（控制台）。
  3. 如果 Chrome 阻止粘贴，先手动输入 allow pasting 并回车。
  4. 粘贴下面的代码并执行，在控制台显示 Token 后复制结果。
const iframe = document.createElement('iframe');
console.log(
  'Token: %c%s',
  'font-size:16px;',
  JSON.parse(document.body.appendChild(iframe).contentWindow.localStorage.token)
);
iframe.remove();
{{ icon('shield-key', 'ui-icon--sm') }}Token 可能过期；遇到 401 时请重新获取。认证信息只保存在本机，并且需要 Discord 账号具备对应服务器权限。

{{ icon('key', 'ui-icon--sm') }}类脑 Cookie 预览

类脑 Cookie 只用于卡片中的帖子详情预览，不等同于 Discord Token 或 Discord 用户 Cookie。

  1. 打开并登录 类脑镜像站。
  2. 按 F12 打开开发者工具，在 Network 面板刷新页面。
  3. 找到详情请求，在 Request Headers 中复制完整 Cookie，优先包含 session= 的整段值。
  4. 粘贴到“类脑 Cookie”字段并保存；预览失败时先重新登录并更新 Cookie。
{{ icon('shield-check', 'ui-icon--sm') }}Cookie 默认隐藏，只保存在本机，显示按钮只影响当前设置页面。

{{ icon('settings-maintenance', 'ui-icon--sm') }}维护操作与数据备份

  • 立即扫描、配置备份、回收站和用户 DB 导入导出：点击后立即执行，不需要先保存设置。
  • 用户 DB 备份：包含收藏、剪贴板、历史和监控池，不会覆盖角色卡、世界书等资源文件。

{{ icon('sliders-settings', 'ui-icon--sm') }}扫描、索引与快照

{{ icon('info', 'ui-icon--sm') }}修改高级策略后建议观察一次扫描或快照状态，确认磁盘空间和响应速度符合预期。
