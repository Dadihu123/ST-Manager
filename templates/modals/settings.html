{{ icon('folder-path', 'ui-icon--sm ') }} 路径配置说明

各路径支持相对路径（相对于程序根目录）或绝对路径。

  • 角色卡路径：存放PNG/JSON格式角色卡的目录
  • 世界书路径：存放全局共享世界书的目录
  • 预设路径：存放AI生成参数预设的目录
  • 资源路径：存放角色附件、背景图等资源的根目录
  • 聊天、正则、脚本与快速回复：分别对应全局扩展资源目录，便于统一浏览和维护
  • ST Chat Completion 预设：可单独接入 SillyTavern 的 OpenAI 预设目录
{{ icon('idea', 'ui-icon--sm ') }} 修改路径后，建议执行“同步扫描”以重新索引文件。

{{ icon('palette', 'ui-icon--sm ') }} 外观设置说明

  • 深浅色模式：切换日间/夜间配色方案
  • 主题强调色：界面主色调，影响按钮、选中状态等
  • 字体风格：界面字体类型（无衬线/衬线/等宽）
  • 卡片宽度：网格视图中卡片的基础宽度
  • 每页数量：设置为0时自动根据屏幕尺寸计算
  • 隔离分类：隐藏分类在上级目录和搜索结果中的出现，但不影响进入分类后浏览
  • 收藏卡片前置：开启后，收藏项会优先排列在角色卡列表顶部

{{ icon('shield-key', 'ui-icon--sm ') }} ST 认证模式排查

先打开 SillyTavern 根目录下的 config.yaml，重点检查 basicAuthMode、enableUserAccounts、perUserBasicAuth、basicAuthUser。

  • Basic/Auth：适合 basicAuthMode: true 且未使用 Web 账号登录。
  • Web/Login：适合 basicAuthMode: false 且 enableUserAccounts: true。
  • Basic Auth + Web Login：适合两者同时开启。
  • perUserBasicAuth: true 时，Basic/Auth 直接复用 Web 账号的 handle/password。
  • perUserBasicAuth: false 时，Basic/Auth 必须填写 basicAuthUser.username/password。
三种常见配置示例 
# Basic/Auth
basicAuthMode: true
enableUserAccounts: false
perUserBasicAuth: false
basicAuthUser:
  username: admin
  password: change-me

# Web/Login
basicAuthMode: false
enableUserAccounts: true

# Basic/Auth + Web/Login
basicAuthMode: true
enableUserAccounts: true
perUserBasicAuth: false
basicAuthUser:
  username: admin
  password: change-me
Web 用户名是账号 handle，可在 Account / Manage Users 中查看；Web 密码无法直接查询，只能验证、修改，忘记时请使用官方 recover.js 流程重置。

{{ icon('plug', 'ui-icon--sm ') }} SillyTavern 集成

配置 SillyTavern 安装根目录后，可检测资源数量，并将资源复制到 ST-Manager 的管理目录。

  • 点击“自动探测路径”尝试自动查找安装目录，也可以手动填写绝对路径
  • 路径应指向包含 data/、public/ 与 server.js 的根目录
  • 验证路径后会显示角色卡、世界书、预设等资源数量
  • 同步前请确认目标目录，避免把同一资源目录配置为来源和目标

{{ icon('settings-connection-service', 'ui-icon--sm ') }} Discord 论坛标签抓取

配置Discord认证后，自动化规则可从类脑论坛帖子抓取标签。

获取 Discord Token 的步骤：
  1. 浏览器打开 Discord 网页版并登录
  2. 按 F12 打开开发者工具
  3. 按 Ctrl + Shift + M 启用移动设备模拟
  4. 切换到 Console（控制台） 标签
  5. Chrome 新版如提示无法粘贴，请先输入 allow pasting 解锁
  6. 粘贴以下代码并回车： 
    const iframe = document.createElement('iframe');
console.log(
  'Token: %c%s',
  'font-size:16px;',
  JSON.parse(document.body.appendChild(iframe).contentWindow.localStorage.token)
);
iframe.remove();
  7. 控制台显示 Token: xxx，复制该值
  8. 在下方 Discord Token 输入框中粘贴保存
注意事项：
  • Token 有过期时间，通常几小时到几天不等
  • 如遇 401 错误，请重新获取 Token
  • Token 仅保存在本地，不会上传到任何服务器
  • 需要 Discord 账号已加入类脑服务器并有访问权限

{{ icon('key', 'ui-icon--sm ') }} 类脑搜索预览

类脑 Cookie 只用于打开卡片中的帖子详情预览，与 Discord 标签抓取使用的认证信息相互独立。

  • 登录类脑镜像站后，从浏览器开发者工具的 Network 请求中复制完整 Cookie
  • 优先复制包含 session= 的整段值，并粘贴到“类脑 Cookie”输入框
  • Cookie 只保存在本机；预览失败时先重新登录并更新 Cookie

{{ icon('settings-maintenance', 'ui-icon--sm ') }} 维护功能说明

  • 同步扫描：强制扫描所有目录并修复数据库索引
  • 备份数据：备份 ui_data.json 到根目录
  • 回收站：管理已删除的卡片，可恢复或彻底删除
  • 用户数据库备份：备份或恢复收藏、标签、隔离分类等用户状态，不影响资源文件

{{ icon('sliders-settings', 'ui-icon--sm ') }} 高级选项

  • 自动化标签分隔符：控制是否将 / 作为标签分隔符
  • 智能自动快照：定时检查变更并创建备份
  • 快照保留数量：分别限制手动快照和自动快照的保留上限，超出后优先删除最旧记录
  • PNG确定性排序：避免改变外部工具的字节级行为
  • 世界书预览限制：防止大型世界书卡死界面
